How the engine scores and ranks numbers.

Model Overview

This site uses a weighted model combining:

  • Structural patterns: odd/even, low/high, decades, primes, sum range, consecutive pairs
  • Frequency: long-term hot/cold behaviour
  • Recency: last N draws, streaks
  • Pair clustering: numbers that often appear together

Modes adjust the weights:

  • Conservative: structure-focused
  • Hybrid: balanced structure + momentum
  • Aggressive: momentum-focused
