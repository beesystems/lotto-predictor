# lotto-predictor
Free Lotto Predictor - Canadian Lotto 6/49 Analytics

A clean, multi‑page analytics dashboard that predicts Lotto 6/49 numbers using structural patterns, frequency analysis, recency momentum, and pair clustering. Built with HTML, CSS, JavaScript, and Chart.js, and deployed via GitHub Pages.
